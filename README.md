# DevConnect

DevConnect is a social networking application designed for developers to connect, share content, and engage with each other. Built with a React client, Express backend, and MongoDB database, this application allows users to log in, register, post content, and reply to posts.

## Features

- **User Authentication**: Register and log in to the application.
- **Post Content**: Share updates, thoughts, or articles with other developers.
- **Reply to Posts**: Engage with others by replying to their posts.
- **Responsive Design**: Works seamlessly on both desktop and mobile devices.

## Technologies

- **Frontend**: React
- **Backend**: Express
- **Database**: MongoDB

## Installation
1. **Clone the repository:**

   ```bash
   git clone https://github.com/daniel-enere/devconnect.git
   
2. **Navigate to the project directory:**
   ```bash
   cd devconnect
	
3. **Install server dependencies:**
   ```bash
   npm install


4. **Install client dependencies:**
   ```bash
   cd client
   npm install

	
5. **Run the development server:**
   ```bash
   npm run dev
   
### Prerequisites

- Node.js (v14 or later)
- npm or yarn
- MongoDB (local or a cloud instance)

## Usage

- **Register**: Create a new account by navigating to the registration page on the React client.
- **Login**: Use your credentials to log in and access the app's features.
- **Post Content**: After logging in, you can post content to share with other developers.
- **Reply to Posts**: Engage with posts by replying to them.
